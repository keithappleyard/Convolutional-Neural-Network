This is my implementation of a convolutional neural network (CNN) in python without the use of pytorch or tensorflow.
The aim of this model is to classify images from the CIFAR-10 dataset into the correct classifications, with measures of loss and accuracy per iteration.

The following file must be installed and within the same directory as the files from this website: https://www.cs.toronto.edu/~kriz/cifar.html
cifar-10-python.tar.gz
